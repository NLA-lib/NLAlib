# Vocabulary

Part of the [contributor guide](../../CONTRIBUTING.md).

One spelling per concept. The table is the current state; it grows only through a design note
([design](design.md)) and the PR that adds the row together with its bridge. Checked spellings:
raw orthonormality
`Qᴴ * Q = 1` [V1], truncated `Fintype.card n - k` [V2], a spelled-out singular-value ratio [V3],
`frobNorm A * frobNorm A` [V4], the forbidden names of the rows below [V5]; every Lean name the
guides or `docs/design/Mathlib-deviations.md` cite exists [V6] (except in
[naming](naming.md), whose names are patterns); a public definition named in neither is on a
review list [V7], unless the explorer marks it as supporting infrastructure.
